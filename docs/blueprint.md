# **App Name**: Isra Ethnic

## Core Features:

- Luxury Catalog Grid: An elegant, image-heavy gallery showcasing the latest churidar and saree collections with a clean minimalist layout.
- AI Personal Drape Tool: An AI-powered styling tool where users can describe an occasion, and it recommends specific saree fabrics or churidar cuts available in-store.
- Direct Shop Connect: One-touch floating buttons to call or WhatsApp the shop directly using the provided numbers 8113081120 or 9961264495.
- Live Instagram Reel Stream: Seamlessly integrates the latest trending posts from the @isra.ethnic Instagram account into the home page.
- Pattern Trend Analysis Tool: An AI tool that suggests matching blouse designs and accessory colors for any saree pattern a user describes.
- Boutique Locator: Dedicated section featuring the shop’s Thekkummuri, Tirur address with an embedded interactive map for easy directions.

## Style Guidelines:

- Primary color: Sophisticated Satin Gold (#C5A059) used for accents, branding, and sophisticated borders, mirroring the shop's logo.
- Background color: A deep, muted Earthy Charcoal (#161410) that allows the gold and product photos to pop with high-end contrast.
- Accent color: Deep Burnt Crimson (#A32F29), used sparingly for Call-to-Action buttons and promotional highlights to evoke ethnic warmth.
- Font pairing: 'Playfair' (serif) for headlines to provide a high-end editorial look, paired with 'PT Sans' (sans-serif) for body text and navigation.
- Fine-line vector icons inspired by textile patterns and traditional Indian jewelry motifs.
- Asymmetrical masonry grid for product galleries to give the site an 'agency-style' look, rather than a generic e-commerce layout.
- Staggered fade-in effects and smooth parallax scrolling for large saree imagery to create a premium browsing experience.
